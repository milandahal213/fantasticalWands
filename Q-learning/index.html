New to reinforcement learning? Here's the whole idea, from the ground up. ↓

What problem does this solve?

Suppose you want a robot or a program to make good decisions in some environment — navigate a maze, follow a line, play a game — but you don't actually know the best strategy yourself. Hardcoding a fixed set of rules only works if you can anticipate every situation in advance. Reinforcement learning takes a different approach: instead of telling the agent what to do, you tell it what counts as good (a reward signal), and let it work out the behavior through trial and error.

Q-learning is one of the simplest and most widely taught reinforcement learning algorithms. It keeps a table of values — one for every combination of "situation" and "action available in that situation" — and updates that table after every single step the agent takes.

The agent-environment loop

Every reinforcement learning problem boils down to this loop: the agent looks at its current state, picks an action, and the environment responds with a new state and a reward. That reward is the only feedback the agent ever gets — there's no separate "here's the right answer" signal.

The only information that ever flows back to the agent is a number: the reward.

What's actually in the table?

A Q-table has one row per state and one column per possible action. Each cell, Q(state, action), is the agent's current best guess at "if I take this action from this state, and then act optimally forever after, how much total reward should I expect?" Every cell starts at zero — the agent begins knowing nothing — and gets nudged after every step using the Bellman equation:

Q(s,a) ← Q(s,a) + α × [ reward + γ × max(Q(s′)) − Q(s,a) ]

α (learning rate) controls how much each new experience overwrites the old estimate. γ (discount) controls how much future reward matters compared to an immediate one. max(Q(s′)) is the best value available from wherever the action leads — this is what lets reward earned far in the future ripple backward through every step that led there.

Exploration vs. exploitation

If the agent always picked the action its table currently rates highest, it could get stuck with a mediocre strategy just because that's what it happened to try first. So Q-learning usually mixes in some randomness — called ε-greedy exploration — taking a random action some percentage of the time, purely to keep discovering whether something better exists.
